# **Spooky Ghost Menu - Now ported to Xbox and Xbox 360!**

Many HCM cheats, features, and options ported to Xbox/360, including the Ghost Viewer and my Superbounce Viewer, with Harc's Monster/Dreadnought additions. All with just a modified xbe.

Download and open the patcher. Select the version you want, select output location, then place the xbe in the appropriate game folder on your Xbox/360.
  
#
  
Place the "spots" folder for Monsters/Dreadnoughts in your TDATA's 4d530064 folder for them to work.  
  
**Xbox**: /E/TDATA/4d530064/spots  
**360**: /Hdd1/Compatibility/Xbox1/TDATA/4d530064/spots  
#  
**Shortcuts (menu closed, in game):**
  
- **Back + D-pad Up**: Open or close the menu
- **Back + D-pad Left**: Create Checkpoint
- **Back + D-pad Right**: Revert Checkpoint
- **Back + D-pad Down**: Third Person Camera on or off
- **Back + Black**: Free Camera on or off
- **Back + White**: Teleport to the free camera
- **Black + D-pad Up**: Launch
- **Black + D-pad Down**: Teleport
- **Black + D-pad Left**: Save offsets (while the Ghost Viewer is on)
- **Black + D-pad Right**: Revert offsets (while the Ghost Viewer is on)
- **White + D-pad Left**: Game Speed −0.1
- **White + D-pad Right**: Game Speed +0.1
- **White + D-pad Down**: Pause Game on or off
