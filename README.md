## **Spooky Ghost Menu v2.0 - Now ported to Xbox and Xbox 360!**

Many HCM cheats, features, and options ported to Xbox/360, including the Ghost Viewer and my Superbounce Viewer, all with just a modified xbe. 128MB features now enabled via a modified Xbox 360 emulator as well.

Download and open the patcher. Select the version you want, select output location, then place the xbe (and xefu1_1.xex) in the appropriate game folder on your Xbox/360.


## **NEW IN V2.0 - 128MB FEATURES**

- **Mod now includes 128MB support**, whether it be via an OG Devkit/128MB-modded Xbox, or via Spooky Ghost's Xbox 360 emulator mod. (**NOTE**: Emulator expected/used as base: FATXplorer's "Hacked Version" Emulator Files. Uses the "HUD" version- either 64MB or 128MB will work for the patcher.) Every build has the game’s 64MB limit flag cleared so it can use the extra memory; on a 64MB console these options are refused or greyed out.
- **Larger Caches**: moves the geometry and animation caches into the mod’s own memory and gives the freed space to the texture cache. Measured on the 360: texture cache 18.8 to 26.7 MB, geometry 7 to 16MB, with less texture pop-in. It is turned on by default when 128MB is detected.  
- **Render Scale 110–200%**: upscales the in-game render resolution.

## **Controller Shortcuts:**
  
- **Back + D-pad Up**: Open or close the menu
- **White (while menu is open)**: Hold to hide menu and regain control- once released, the menu reopens
- **Back + D-pad Left**: Create Checkpoint
- **Back + D-pad Right**: Revert Checkpoint
- **Back + D-pad Down**: Third Person Camera on or off
- **Back + Black**: Free Camera on or off
- **Back + White**: Teleport to the free camera
- **Black + White (while in freecam)**: Enable/disable player movement
- **Black + D-pad Up**: Launch
- **Black + D-pad Down**: Teleport
- **Black + D-pad Left**: Save offsets (while the Ghost Viewer is on)
- **Black + D-pad Right**: Revert offsets (while the Ghost Viewer is on)
- **White + D-pad Left**: Game Speed −0.1
- **White + D-pad Right**: Game Speed +0.1
- **White + D-pad Down**: Pause Game on or off
