Each build opens a Save dialog with the name default.xbe filled in — choose where it goes (Desktop, Downloads, any folder). A new folder for each build is easiest: if the folder already has a default.xbe — maybe your original — Windows asks before replacing it.

With Xbox 360 ticked, a build saves one zip instead, holding both files: default.xbe and the emulator, xefu1_1.xex (R89). Extract it where you like. The emulator replaces the one in the console's Compatibility folder — keep a copy of the original.

Your files never leave your computer: the patching happens in this page. Every place the mod changes is checked against the original first; a modified or unknown file is refused, and the finished emulator is checked against the release build before it is saved.

The Monster/Dreadnought Viewer also needs the spots folder from the Spooky Ghost package, copied to E:\TDATA\4D530064\spots on the Xbox.
